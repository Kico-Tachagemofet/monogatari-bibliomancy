# 物语书占（Monogatari Bibliomancy）

这个 skill 只负责**素材**：抽页、定位、调出背景卡片。解读一律交给 `bibliomancy-reading`，本 skill 不另立解读方法。

## 前置条件

- 本地有物语系列 epub，并已按分页规则建好页码表（配置中 `state_dir` 下的 `page_index.json`、`manifest.json`）。本私人 review 版附带 18 本 epub，每次从本地 epub 实时读出；书籍不适用本仓库代码或卡片的开放许可证。
- 话卡数据 `data/arc_cards.json`：每一话的怪异、主角、主旨，以及按进度划分的阶段，每段有“一句话 + 在场人物此刻的状态和立场”。
- 控制台报编码错误时，先设置 `PYTHONIOENCODING=utf-8`。

## 流程（按顺序，不跳步）

### 1. 确认问题，再抽

- 逐字记下提问者的问题。没有具体问题时记为“无主题书占”。
- **抽取前**把问题复述给提问者确认。抽取一旦发生就作数，问题改不了。

### 2. 抽一次，不重抽

```
python tools/monogatari/draw.py draw --question "<问题原文>"
```

- 脚本先把这次抽取写进日志（时间、问题、全局页码、页码表校验值），再输出这一页原文和同一话内的前后语境。
- **只抽一次。** 不因为“这页不好读”“没有怪异出场”“不像答案”而重抽；也不用 `show` 去翻别的页来替代。
- 如果抽取后输出失败，错误信息会给出已经记入日志的页码，用它恢复，**不要再执行 draw**：

```
python tools/monogatari/draw.py show --page <N>
```

- 追问沿用同一页，不重抽。

### 3. 查出这一页的位置和背景

```
python tools/monogatari/lookup.py --page <N>
```

它只读数据，不抽取、不写日志、不输出原文。输出包括：

- 书、分册、本书页码、话名、本话第几页；
- 话卡：怪异（附“它替人承担了什么”“没有它，必须承认什么”）、主角、主旨；
- 本页所在阶段：第几段、段名、页码范围、**本页是本段第几页**，以及这一段的一句话和人物栏；
- 上一段的一句话，作为紧接着的前情；
- 本页不是本段第一页时，列出“前情可查”的页码范围（同一段里本页之前的页）。

### 3.5 读同段前情（按需，只读）

抽取输出里的前后语境通常只有一两句，而决定人物此刻立场的话，常常就在同一段里本页之前几页（例如招揽的条件、先前的称呼、赌注）。所以：

- 可以用 `python tools/monogatari/draw.py show --page <M>` **只读查看**查询结果列出的前情页，作为背景。`show` 不抽取、不写日志。
- **只看本页之前的页，本页之后的一页都不看**，也不引用。
- 前情只作背景，不替代本页：解读的主体仍是抽到的这一页。归档时前情单独列一节“前情（转述）”，并写明看了哪几页。
- 人物心理、关系、对话类问题，建议读完同段前情再开读；处境类、无主题书占可以只看本页。

### 4. 交给解读法

**必须实际调用 `bibliomancy-reading` skill** 来读，不要只凭本 skill 的提示徒手写。交给它的材料：

- 问题原文；
- 本页原文（前后语境另外标注，不当作本页）；
- 读过的同段前情（转述，注明页码，标为背景）；
- 第 3 步查出的出处、话卡、阶段人物栏和上一段摘要。

交接时附上下面这些物语专用的读法提示。

## 物语素材的读法提示（交给解读法时一并遵守）

1. **卡片只是背景。** 话卡和人物栏是参照，不是答案；解读仍以这一页的场景和意象为主，不照卡片逐条对号入座。
2. **人物栏描述的是整段。** 如果本页不是这一段的最后一页（查询结果会提示），人物栏里可能写到了本页之后才发生的事。**一切以本页原文为准**：本页还没发生的内容，不能当作已经发生来引用，也不能用来推结果。
3. **人物按“这一段”的时期理解。** 人物栏写的就是这个人物此刻的状态和立场；同一个人在别的书、别的时期，意思可能完全不同。解读中涉及人物时，写明按哪个时期理解。
4. **叙述者不固定。** 大多数话由阿良良木历叙述，但也有羽川、抚子、贝木、神原等人叙述的话，以及对谈框架、回放、预叙、梦境、书信。人物栏里的“（回放）”“（预叙）”“（叙述框架）”“（梦境）”“（电话）”等标注要保留，不能把它们当作现场正在发生的事。
5. **叙述者可能不可靠。** 有的话叙述者自己在隐瞒或误解（例如把虚构的对话对象讲得像真的）。人物栏里标成“某某所述”“推测”“据叙述推断”的内容，只能当作叙述者的说法。
6. **本页不一定有怪异出场。** 抽到日常闲谈、斗嘴时，要区分“本页画面”和“本话主旨”；闲谈页的分量本身就是答案的一部分。
7. **不看后续。** 只用这一页之前已经发生、已经揭示的事（包括剧情时间更早的其他书）；这一页之后的剧情、人物后来的命运、后面才揭晓的真相，一律不引用。
8. **没有人物卡时。** 如果本地还没有人物卡，人物的核心寓意只能依靠人物栏和对作品的一般了解；后者要标注为背景知识，不当作页面证据。

## 输出

先列抽取信息，再接解读法的输出模板：

```markdown
## 抽取
| 项目 | 结果 |
|---|---|
| 问题 | （原文） |
| 全局页 | N |
| 书 | 书名（分册），本书第 x 页 |
| 话 | 话名，本话第 a/b 页 |
| 阶段 | 第 k/m 段「段名」（本页是本段第 p/q 页） |
| 日志 | 抽取日志中的这一条；页码表校验值前 8 位 |
| 前情 | 读过的同段前情页（如有），或“未读” |

原文不在此转录。本地查看：`python tools/monogatari/draw.py show --page N`
```

- 引用原文只取指认画面所需的**短句**，不整页转录。
- 之后按 `bibliomancy-reading` 的模板一次读完，结尾必须主动询问解读是否贴切，并列出针对这一页的追问方向。

## 归档

- 归档位置由本地项目规则决定，本 skill 不写死路径。
- **先给预览，提问者确认后才写入；只新建，不覆盖。**
- 归档内容：问题、抽取信息表、页面情境的转述（不整页转录原文）、定稿解读、提问者的纠正记录、留白。纠正要照实记下，它是解读的一部分。

## 禁令

- 不重抽；不用 `show` 挑别的页来替代抽到的页；抽取失败只用日志里的页码恢复。`show` 只用于三件事：恢复抽到的页、查看同段本页之前的前情、提问者要求重看已抽的页。
- 不看、不引用本页之后的页。
- 不修改页码表、话卡或日志；本 skill 只读数据，只有 `draw` 会写日志。
- 不把人物栏或话卡写成“页面证据”；它们属于背景。
- 不引用本页之后的剧情。
- 不套塔罗、易经或 Lite 符号包的解读流程。
