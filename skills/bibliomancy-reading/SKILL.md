# 书占解读法（Bibliomancy Reading）

把一段随机抽到的文本，当作**一个正在发生的场景**来读，而不是当作神谕式的箴言。读法的核心是：先把眼前的画面和意象读透，再引入人物与背景，最后一层层落回提问者自己的处境。

## 何时使用

- 已经有一段抽到的文本，以及一个问题（也可能没有具体问题）。
- 文本可以来自任何书；如果来自某个素材层 skill（例如物语书占），它会一并提供背景：这一页属于哪一段故事、所处阶段、在场人物此刻的状态、人物卡等。
- **不用于**：塔罗、易经、Lite 完整符号包（它们各有自己的 skill）。书占是直接的文本细读，不虚构任何塔罗式的属性层流程。

## 输入

- 问题原文（逐字保留）。没有具体问题时，记为“无主题书占”。
- 抽到的文本；可以附带前后一两句语境，但**以这一页为主体**。
- 素材层提供的背景（可选）：书、段落、阶段、在场人物状态、人物卡、主旨卡。
- 提问者提供的补充信息（可选）：例如事情经过、以前核对过的结论。

## 权重原则

1. **场景与意象优先**：先读眼前这一页的画面，以及其中物件、动作、意象之间的互动；然后才看在场的人物。
2. **背景只是背景**：主旨卡、人物卡、人物状态栏都是参照，不是答案。可以从意象出发自由联想，**不能照着卡片逐条对号入座**。
3. **同一页，不同问题，读法不同**：见第 0 步。

## 读法（一次读完，中途不停）

### 第 0 步 · 判断题型，决定重心

| 题型 | 以哪一层为主 |
|---|---|
| 某人的心理、关系、一次对话 | 在场人物此刻的状态和立场；一个人可以同时对应页面上的几个角色 |
| 处境、事情的走向 | 场景意象，以及这一页在所属段落里的位置 |
| 提问者自身的内在状态 | 意象，以及页面里的异常“替人承担了什么” |
| 没有具体题目 | 以意象为主，自由发散 |

### 第 1 步 · 原文情境与叙述者

- 先把画面说实：谁在场，在哪里，在做什么，说了什么；这一页里突出的物件、动作和意象。这一步不急着象征化。
- 再判断叙述者：谁在说？处在人生或剧情的哪一段？此刻知道多少？他的评价要不要打折扣（自嘲、夸张、事后补评、偏见）？
- **叙述者所处的阶段本身就是一层滤镜**。回忆录尤其要分清“当时”和“后来回看”这两个时间。
- 只标出“叙述者的认知有局限”，**不借这一页之后的内容去揭示真相**。

### 第 2 步 · 意象与人物的抽象互动，包括方式

- 意象之间、人与意象之间怎样作用；人与人之间是什么关系。
- 把互动提炼成带方向的动作结构：谁向谁试探、遮掩、托付、拒绝、交换，谁主动，谁被动。
- **同时读方式**：他们怎么做事、怎么说话，是琐碎还是郑重，是分隔还是混杂，是玩闹还是正面相对。方式往往比情节更接近主题。
- 对话密集的文本里，斗嘴、口误、双关、名字的字面含义本身就在承载意思。

### 第 3 步 · 反常点与分量

- 找出错位的、说不通的、边缘人物抢戏的地方。
- 主动问这一页**有多重**：主角是不是边缘人物？讲的是不是一件小事？抽到的是正戏还是日常闲谈？**这一页的分量本身就是答案的一部分。**

### 第 4 步 · 背景滤镜与人物时期

- 使用素材层提供的背景：这一段是谁的故事，主旨是什么，异常以什么方式作用在人身上。
- 凡是牵涉人物的地方，**写明你按哪个时期理解这个人物**。同一个人在不同时期，意思可能完全不同。这一页**之前**已经发生的事，可以用，也应该用。
- 没有素材层背景时，使用你对作者和作品的一般了解，但要标注这是背景知识，不是页面内容。

### 第 5 步 · 相对位置

- 这一页处在所属段落的哪个阶段：只描述这是什么样的事、正在产生什么样的互动。
- **不用后面的剧情推结果**，也不借人物后来的命运给结论打气。

### 第 6 步 · 映射到问题

- 把第 2 步的互动结构对到提问者的情境上，一层一层展开。
- **每一层都要落回提问者自己的具体领域**，举出他生活里可能对应的情形，不停在抽象结构上。
- 书中角色可以对应到提问者本人，或者他关系中的人，而且可以一人对应多个角色。但对应只作**类比**，不作断言，也不借剧情补完现实里的时间、对象、事情的大小和范围。
- 每个类比都要**说出它在哪一步断开**：页面里的对象、处境或动机，哪一部分不能直接搬到现实里。例如页面上被反对的是某个具体存在，就不能直接替换成现实中某个人反对的具体东西。
- 提问者如果提供了、或指向了相关材料（他写的文章、以前的记录），可以调用，让类比落到具体文本上；调用时注明出处，并归入证据第②层。
- 可选角度（阴暗面）：表层事件 → 谁在承担症状 → 被压住的是什么 → 这个结构保护了什么 → 代价 → 转机在承认、行动、边界还是关系。**只作为可选角度**，不能每次都收束到“接纳”“重新命名”这类固定答案。

### 第 7 步 · 留白与可纠正

- 没对上的地方如实标出，不下定论。
- 牵涉前情、人物时期的判断，都写明自己的理解，方便提问者纠正。
- 解读不是最终判断，否决权在提问者。

## 结尾：主动询问，并给出追问方向（必做）

读完之后不要就此收尾。每一次解读的结尾都要做两件事：

1. **主动询问提问者的感受**：这份解读读起来贴不贴？哪里对上了？哪里读偏了？特别点出你最没把握的一两处，例如人物时期、某个类比，请提问者确认。提问者比解读者更了解自己的处境，往往也更熟悉原作，他的纠正是解读的一部分。
2. **列出 2–4 个具体的追问方向**：必须是**针对这一页**的，不能是“还有什么想问的吗”这种空泛的问法。从下面的追问模式里挑最有潜力的几个，写明挖什么、为什么值得挖。例如：
   - 用页面上的某个角色当透镜：他和这一页的核心问题是什么关系？
   - 单独展开某个意象：这个物件或动作在页面里承担了什么？
   - 换一个题型重读：如果把问题换成处境类或内在状态类，重心会移到哪里？
   - 把某个悬而未决的类比继续推一步，同时说清它会在哪里断开。

追问方向只是提议，由提问者决定挖不挖、挖哪一个。追问一律使用同一页，不重抽。

## 追问模式（同一页，不重抽，往深处挖）

读完之后，提问者常常会接着追问。追问一律使用**同一页**，不抽新的页面。常用的几种挖法：

1. **角色透镜**：选页面上的一个角色，问的不是“他对应谁”，而是“**他和这一页的核心问题是什么关系**”：他怎么面对这个问题？他的立场从哪里来？他本人是不是也困在这个问题里？一个角色的敌意或判断，常常不是站在问题之外的公正裁判，而是带着自身经历的当事人判断。
2. **把关系搬过去**：用这个角色与核心问题的关系，去理解现实中某个人与他那个问题的关系。这种对应是**关系对关系**，不是身份对身份，往往比“谁对应谁”走得更深。
3. **意象透镜**：选一个意象（一个物件、一个动作）单独展开，问它在页面里承担了什么功能，再问它在提问者的情境里对应什么。
4. **换题型重读**：同一页，按第 0 步换一个题型重读，看重心移到哪里。

追问时仍然遵守全部规则：只用这一页之前的信息；说出类比在哪里断开；证据分层。

## 证据分层

输出时把三种来源分开：

1. **页面**：这一页上实际写了什么。
2. **提问者提供**：提问者给出或核对过的信息。
3. **推测**：解读者自己的推断。

问第三方心理时尤其要守住这一点，**不能把推测说成页面证据**。

## 输出模板

```markdown
## 抽取
（出处：书名 / 段落 / 页码或位置 / 所处阶段；由素材层提供时照录）

### 0. 题型与重心
### 1. 原文情境与叙述者
### 2. 意象与互动（含方式）
### 3. 反常点与分量
### 4. 背景滤镜（写明人物按哪个时期理解）
### 5. 相对位置
### 6. 映射到问题（逐层展开，每层落到具体领域；标注对应只是类比，并说明在哪里断开）
### 问题的重新表述（可选）
（这一页有时会把问题本身换一种问法；如果有，在这里写出来）
### 7. 留白

### 这样读对吗？可以接着追问的方向
（先问提问者：这份解读读起来贴不贴，哪里对上了，哪里读偏了；再列 2–4 个具体的追问方向）
```

- 引用原文只取必要的**短句**，用来指认画面；不整页转录。需要看全文时，告诉提问者在哪里查看。
- 语言跟随问题的语言。
- 解读中的判断要写到能被检验的程度，不要用空泛的套话收尾。

## 禁令

- 不引用这一页之后的剧情、人物后来的命运或结局（不做“全局把控”）。
- 不把对应写成断言；不补完时间、对象、量级、范围。
- 不套塔罗、易经或 Lite 符号包的解读流程；不声称跑过任何其他 skill 的 pipeline。
- 不重抽。抽到的文本已经作数；如果对抽取本身有疑问，如实说明，不用新的一页替换。
- 归档由调用方负责：先给预览，得到确认之后才写入，只新建，不覆盖。

## 反面清单（常见读偏）

- 只看人物不看画面：还没读意象就开始给人物贴寓意。
- 照卡套读：把主旨卡逐条对到问题上。
- 用错人物时期：按人物最有名的形象读，而不是按这一页所处时期的形象读。
- 借后文揭晓：用这一页之后才揭示的真相解释这一页。
- 停在抽象：映射只说到“一种结构”，没有落到提问者的生活里。
- 推测冒充证据：把“可能是”写成“页面显示”。
